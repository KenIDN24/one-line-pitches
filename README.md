## The line

## Run it

```sh
node main.ts
```

`main.ts` writes that single sentence (193 characters, within the 240-character cap) to `/output/entry.txt`. It checks the length first and refuses to write an entry outside the 1–240 character gate, and it checks the text is exactly one sentence.
